1. ¿QUÉ ES LA LIBRERÍA DE COLORES?
================================================================================

Es un sistema que te permite:
✅ Tener todos los colores en UN SOLO LUGAR
✅ Cambiar un color y que se actualice EN TODA LA APLICACIÓN automáticamente
✅ Soporte automático para modo claro y modo oscuro
✅ 20+ colores predefinidos y organizados
✅ Fácil mantenimiento

ANTES (Sin librería):
- Colores hardcodeados en cada archivo
- Difícil mantener consistencia
- Cambiar un color = editar múltiples archivos

DESPUÉS (Con librería):
- Un solo lugar para todos los colores
- Cambiar un color = editar 1 línea
- Consistencia automática

2. ESTRUCTURA DE ARCHIVOS
================================================================================

Tu proyecto tiene estos archivos importantes:

📁 proyecto/
│
├── 📁 app/
│   ├── 📄 globals.css          ← AQUÍ están los colores (CSS Variables)
│   └── 📄 page.tsx             ← Página que usa los colores
│
├── 📁 lib/
│   └── 📄 colors.ts            ← Librería TypeScript para importar
│
└── 📁 components/
    ├── 📄 Button.tsx           ← Botón que usa los colores
    ├── 📄 Card.tsx             ← Tarjeta que usa los colores
    └── 📄 ColorDemo.tsx        ← Demostración de todos los colores

IMPORTANTE: Solo necesitas tocar globals.css para cambiar colores!

3. CÓMO ESTÁ ORGANIZADA
================================================================================

Los colores están organizados en 8 categorías:

🎨 CATEGORÍAS DE COLORES:
=========================

1. COLORES BASE
   - background-color         → Fondo principal
   - background-secondary     → Fondo secundario  
   - foreground-color         → Texto principal
   - foreground-secondary     → Texto secundario

2. COLORES PRINCIPALES
   - primary-color           → Color primario de tu marca
   - primary-hover           → Cuando pasas el mouse
   - primary-light           → Versión clara
   - primary-dark            → Versión oscura

3. COLORES SECUNDARIOS
   - secondary-color         → Color secundario
   - secondary-hover         → Hover del secundario
   - secondary-light         → Secundario claro
   - secondary-dark          → Secundario oscuro

4. COLORES DE ACENTO
   - accent-color            → Color de acento/destacado
   - accent-hover            → Hover del acento
   - accent-light            → Acento claro
   - accent-dark             → Acento oscuro

5. COLORES DE BOTONES (LOS MÁS IMPORTANTES)
   - button-color-principal  → Botón principal (azul)
   - button-color-secundario → Botón secundario (gris)
   - button-color-success    → Botón de éxito (verde)
   - button-color-danger     → Botón de peligro (rojo)
   - button-color-warning    → Botón de advertencia (naranja)

6. ESTADOS DE INTERACCIÓN
   - color-success           → Verde para éxito
   - color-error             → Rojo para errores
   - color-warning           → Naranja para advertencias
   - color-info              → Azul para información

7. ESCALA DE GRISES
   - gray-50 a gray-900      → 10 tonos de gris

8. COLORES DE BORDE
   - border-color            → Bordes normales
   - border-color-hover      → Bordes al pasar mouse
   - border-color-focus      → Bordes al hacer click

4. CÓMO USAR LOS COLORES
================================================================================

Hay 3 maneras de usar los colores:

📌 MÉTODO 1: CSS Variables (Directo)
====================================
<div style="background-color: var(--button-color-principal)">
  Mi div azul
</div>

📌 MÉTODO 2: Importando la librería TypeScript
===============================================
import { colors } from '@/lib/colors';

<div style={{ backgroundColor: colors.buttonColorPrincipal }}>
  Mi div azul
</div>

📌 MÉTODO 3: Con Tailwind CSS
=============================
<div className="bg-[var(--button-color-principal)]">
  Mi div azul
</div>

🎯 RECOMENDACIÓN: Usa el Método 2 para tener autocompletado en TypeScript

5. CÓMO CAMBIAR COLORES (FÁCIL)
================================================================================

🚀 PASO A PASO PARA CAMBIAR CUALQUIER COLOR:
============================================

PASO 1: Abre el archivo globals.css
PASO 2: Busca el color que quieres cambiar
PASO 3: Cambia el valor hexadecimal
PASO 4: Guarda el archivo
PASO 5: ¡Listo! Se actualiza automáticamente en toda la app

📍 EJEMPLO: Cambiar el botón principal de azul a verde
===========================================================

1. Abre: app/globals.css

2. Busca la línea (aproximadamente línea 30):
   --button-color-principal: #3b82f6; /* Azul principal */

3. Cambia a:
   --button-color-principal: #10b981; /* Verde principal */

4. Guarda el archivo

5. ¡TODOS los botones principales ahora son verdes!

🌙 PARA MODO OSCURO:
===================
Si quieres un color diferente en modo oscuro:

1. Busca la sección: @media (prefers-color-scheme: dark)
2. Cambia la misma variable ahí
3. Ejemplo:
   --button-color-principal: #34d399; /* Verde más claro para oscuro */

7. CASOS DE USO COMUNES
================================================================================

💡 ¿Cómo hacer que mi componente use un color de la librería?
=============================================================

OPCIÓN A: Con TypeScript (Recomendado)
import { colors } from '@/lib/colors';

const MiComponente = () => {
  return (
    <div style={{ 
      backgroundColor: colors.primaryColor,
      color: colors.foregroundColor,
      border: `1px solid ${colors.borderColor}`
    }}>
      Mi componente
    </div>
  );
};

OPCIÓN B: Con CSS directo
const MiComponente = () => {
  return (
    <div style={{ 
      backgroundColor: 'var(--primary-color)',
      color: 'var(--foreground-color)',
      border: '1px solid var(--border-color)'
    }}>
      Mi componente
    </div>
  );
};

💡 ¿Cómo agregar un nuevo color?
===============================
1. Agrega la variable CSS en globals.css:
   --mi-nuevo-color: #ff6b35;

2. Agrega a colors.ts:
   miNuevoColor: 'var(--mi-nuevo-color)',

3. Usa en tu componente:
   backgroundColor: colors.miNuevoColor

8. SOLUCIÓN DE PROBLEMAS
================================================================================

❌ PROBLEMA: "El color no cambia"
SOLUCIÓN: 
- Verifica que guardaste el archivo globals.css
- Recarga la página en el navegador
- Revisa que el nombre de la variable sea correcto

❌ PROBLEMA: "No encuentro dónde está definido el color"
SOLUCIÓN:
- Todos los colores están en app/globals.css
- Busca el nombre de la variable (ej: --button-color-principal)

❌ PROBLEMA: "El componente no importa los colores"
SOLUCIÓN:
- Asegúrate de importar: import { colors } from '@/lib/colors';
- Usa: colors.nombreDelColor (sin guiones, en camelCase)

❌ PROBLEMA: "Quiero colores diferentes en modo oscuro"
SOLUCIÓN:
- Busca la sección @media (prefers-color-scheme: dark) en globals.css
- Cambia las variables ahí para modo oscuro

❌ PROBLEMA: "No sé qué nombre usar para un color"
SOLUCIÓN:
- Mira la lista completa en la sección 3 de este manual
- O abre lib/colors.ts para ver todos los nombres disponibles

❌ PROBLEMA: "Quiero crear un botón de nuevo color"
SOLUCIÓN:
- Agrega la variable CSS: --button-color-purple: #8b5cf6;
- Modifica components/Button.tsx para agregar case 'purple'
- Usa: <Button variant="purple">Mi botón</Button>

🧩 RESUMEN DEL FLUJO
Definición  
Todos los colores viven en globals.css como variables CSS.

Exposición a TypeScript  
colors.ts convierte esas variables en propiedades con autocompletado.

Consumo en componentes  
Los componentes usan colors.xxx o var(--xxx).

Actualización automática  
Cambias un color en globals.css → toda la app se actualiza.

Modo oscuro integrado  
Las mismas variables tienen versiones para dark mode.
