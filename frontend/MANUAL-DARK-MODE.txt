1. ¿QUÉ ES EL MODO OSCURO?
================================================================================

El modo oscuro es una característica que cambia la interfaz de usuario de colores
claros (fondos blancos, texto negro) a colores oscuros (fondos negros, texto blanco).

BENEFICIOS:
✅ Menos fatiga visual en ambientes con poca luz
✅ Ahorro de batería en pantallas OLED/AMOLED
✅ Mejor experiencia nocturna
✅ Preferencia estética moderna
✅ Accesibilidad mejorada

NUESTRO SISTEMA INCLUYE:
- Toggle manual (botón sol/luna)
- Detección automática de preferencias del sistema
- Persistencia de la elección del usuario
- Transición suave entre modos
- Integración completa con la librería de colores

3. ESTRUCTURA TÉCNICA COMPLETA
================================================================================

🏗️ COMPONENTES INVOLUCRADOS:
=============================

📁 app/dashboard/page.tsx
├── Estado: const [isDarkMode, setIsDarkMode] = useState(false);
├── Detección: useEffect para localStorage y sistema
├── Aplicación: useEffect para clase CSS
└── Toggle: función toggleDarkMode()

📁 components/Login.tsx
├── Misma lógica que dashboard
├── Botón en posición absoluta
└── Iconos y texto idénticos

📁 app/globals.css
├── Variables CSS para modo claro (:root)
├── Variables CSS para modo oscuro (@media prefers-color-scheme: dark)
└── Variables CSS para modo oscuro manual (:root.dark)

📁 lib/colors.ts
└── Todas las variables usan var(--variable) automáticamente

🔧 HOOKS Y FUNCIONES UTILIZADAS:
================================

useState:
- Maneja el estado actual del modo (claro/oscuro)
- Tipo: boolean (false = claro, true = oscuro)

useEffect (Detección):
- Se ejecuta al montar el componente
- Revisa localStorage primero
- Si no hay preferencia → detecta sistema
- Configura listener para cambios del sistema

useEffect (Aplicación):
- Se ejecuta cuando cambia isDarkMode
- Agrega/quita clase "dark" del documento
- Cambia colorScheme del navegador

toggleDarkMode():
- Invierte el estado actual
- Guarda nueva preferencia en localStorage
- Actualiza el estado (dispara useEffect)

🌐 APIS DEL NAVEGADOR UTILIZADAS:
=================================

localStorage:
- Clave: 'theme-override'
- Valores: 'dark' | 'light'
- Persiste entre sesiones

window.matchMedia:
- Media query: '(prefers-color-scheme: dark)'
- Detecta preferencia del sistema operativo
- Listener para cambios en tiempo real

document.documentElement:
- classList.add('dark') / classList.remove('dark')
- style.colorScheme = 'dark' | 'light'

5. PERSISTENCIA DE PREFERENCIAS
================================================================================

💾 CÓMO SE GUARDAN LAS PREFERENCIAS:
====================================

JERARQUÍA DE PREFERENCIAS:
1. Preferencia manual del usuario (localStorage)
2. Preferencia del sistema operativo
3. Modo claro por defecto

FUNCIONAMIENTO DE localStorage:
- Clave: 'theme-override'
- Se crea cuando usuario hace primer toggle
- Se actualiza en cada toggle posterior
- Se lee al cargar la aplicación

CÓDIGO DE EJEMPLO:
// Guardar preferencia
localStorage.setItem('theme-override', 'dark');

// Leer preferencia
const savedTheme = localStorage.getItem('theme-override');

// Borrar preferencia (volver a seguir sistema)
localStorage.removeItem('theme-override');

🔄 LÓGICA DE DECISIÓN:
=====================

AL CARGAR LA APLICACIÓN:
const savedTheme = localStorage.getItem('theme-override');
if (savedTheme) {
    // Usuario ha hecho toggle manual antes
    setIsDarkMode(savedTheme === 'dark');
} else {
    // Primera vez o no ha hecho toggle
    const systemPreference = window.matchMedia('(prefers-color-scheme: dark)');
    setIsDarkMode(systemPreference.matches);
}

AL HACER TOGGLE:
const newMode = !isDarkMode;
setIsDarkMode(newMode);
localStorage.setItem('theme-override', newMode ? 'dark' : 'light');

🌍 PERSISTENCIA ENTRE PÁGINAS:
==============================

✅ Se mantiene al navegar entre Login → Dashboard
✅ Se mantiene al refrescar la página
✅ Se mantiene al cerrar y abrir el navegador
✅ Se mantiene en pestañas diferentes del mismo sitio

6. CSS Y VARIABLES AUTOMÁTICAS
================================================================================

🎨 ESTRUCTURA DE CSS:
=====================

MODO CLARO (Por defecto):
:root {
    --background-color: #ffffff;
    --foreground-color: #171717;
    --primary-color: #3b82f6;
    /* ... 20+ variables más */
}

MODO OSCURO (Automático - Sistema):
@media (prefers-color-scheme: dark) {
    :root {
        --background-color: #0a0a0a;
        --foreground-color: #ededed;
        --primary-color: #60a5fa;
        /* ... mismas variables, colores oscuros */
    }
}

MODO OSCURO (Manual - Toggle):
:root.dark {
    --background-color: #0a0a0a;
    --foreground-color: #ededed;
    --primary-color: #60a5fa;
    /* ... mismas variables, colores oscuros */
}

⚡ CÓMO FUNCIONA LA MAGIA:
=========================

1. COMPONENTES USAN VARIABLES:
style={{ backgroundColor: colors.buttonColorPrincipal }}
↓
style={{ backgroundColor: 'var(--button-color-principal)' }}

2. CSS RESPONDE AL TOGGLE:
- Sin clase .dark → usa valores de :root (modo claro)
- Con clase .dark → usa valores de :root.dark (modo oscuro)

3. CAMBIO INSTANTÁNEO:
document.documentElement.classList.add('dark');
↓ CSS automáticamente cambia TODAS las variables
↓ TODOS los componentes se ven diferentes al instante

🔧 VARIABLES QUE CAMBIAN AUTOMÁTICAMENTE:
=========================================

FONDOS:
--background-color: #ffffff → #0a0a0a
--background-secondary: #f8fafc → #171717

TEXTOS:
--foreground-color: #171717 → #ededed
--foreground-secondary: #64748b → #a1a1aa

BOTONES:
--button-color-principal: #3b82f6 → #60a5fa

BORDES:
--border-color: #e2e8f0 → #374151

GRISES:
--gray-200: #e2e8f0 → #334155

8. SOLUCIÓN DE PROBLEMAS
================================================================================

❌ PROBLEMA: "El toggle no cambia el modo"
SOLUCIÓN:
- Verifica que globals.css esté correcto
- Asegúrate que no haya errores en consola
- Revisa que la clase 'dark' se agregue al <html>

❌ PROBLEMA: "Los colores no cambian"
SOLUCIÓN:
- Verifica que estés usando la librería de colores
- No uses colores hardcodeados como '#ffffff'
- Usa colors.backgroundColor en lugar de valores fijos

❌ PROBLEMA: "No se guarda la preferencia"
SOLUCIÓN:
- Verifica que localStorage funcione en tu navegador
- Revisa que no tengas modo incógnito/privado
- Comprueba que la clave 'theme-override' se guarde

❌ PROBLEMA: "Parpadeo al cargar"
SOLUCIÓN:
- Es normal un micro-parpadeo al detectar preferencias
- Se puede minimizar con SSR avanzado (fuera del alcance)

❌ PROBLEMA: "No detecta preferencia del sistema"
SOLUCIÓN:
- Verifica que tu SO soporte prefers-color-scheme
- Windows: Configuración → Personalización → Colores
- Mac: Preferencias → General → Apariencia

🐛 DEBUGGING:
=============

PARA VERIFICAR QUE FUNCIONA:
1. Abre DevTools → Application → Local Storage
2. Busca clave 'theme-override'
3. Haz toggle → verifica que cambie
4. Recarga página → verifica que se mantenga

PARA VER LAS CLASES CSS:
1. Abre DevTools → Elements
2. Busca el elemento <html>
3. Haz toggle → verifica que aparezca/desaparezca clase 'dark'

PARA VER LAS VARIABLES:
1. Abre DevTools → Elements → Computed
2. Busca cualquier elemento
3. Ve las Custom Properties (variables CSS)
4. Haz toggle → verifica que cambien los valores

9. PERSONALIZACIÓN AVANZADA
================================================================================

🎨 CAMBIAR COLORES DEL MODO OSCURO:
===================================

Para cambiar los colores del modo oscuro:

1. Abre app/globals.css
2. Busca la sección ":root.dark {"
3. Cambia los valores hexadecimales

EJEMPLO - Modo oscuro más azulado:
:root.dark {
    --background-color: #0f0f1f; /* Azul muy oscuro */
    --background-secondary: #1a1a2e;
    --foreground-color: #e6e6ff; /* Texto azul claro */
    /* ... más colores */
}

🔧 AGREGAR NUEVOS ELEMENTOS QUE RESPONDAN:
==========================================

Para que un nuevo componente soporte modo oscuro automáticamente:

CORRECTO:
<div style={{ backgroundColor: colors.primaryColor }}>

INCORRECTO:
<div style={{ backgroundColor: '#3b82f6' }}>

⚡ VERSIÓN ULTRA CORTA DEL RESUMEN
Tu dark mode funciona así:

Al cargar, revisa si el usuario tiene preferencia guardada.

Si no, usa el modo del sistema (claro/oscuro).

Aplica o quita la clase dark en <html>.

El CSS cambia todas las variables de color automáticamente.

El usuario puede cambiar manualmente con un toggle, y se guarda en localStorage.

Todos los componentes cambian solos porque usan var(--color).

En pocas palabras:
Un toggle + una clase CSS + variables centralizadas = modo oscuro perfecto y automático.
