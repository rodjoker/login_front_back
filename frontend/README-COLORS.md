# Librería de Colores - Sistema de Diseño\n\n## Descripción\n\nEsta librería de colores proporciona un sistema centralizado para gestionar todos los colores utilizados en la aplicación. Permite realizar cambios globales de colores desde un solo lugar, asegurando consistencia y facilitando el mantenimiento.\n\n## Características Principales\n\n✅ **20+ colores organizados** por categorías funcionales  \n✅ **Soporte completo** para modo claro y oscuro  \n✅ **CSS Variables** para cambios dinámicos  \n✅ **TypeScript** con tipado completo  \n✅ **Componentes de ejemplo** listos para usar  \n✅ **Fácil mantenimiento** y actualización  \n\n## Estructura de Archivos\n\n```\nproyecto/\n├── app/\n│   ├── globals.css          # Variables CSS con todos los colores\n│   └── page.tsx            # Página de demostración\n├── lib/\n│   └── colors.ts           # Librería TypeScript de colores\n├── components/\n│   ├── Button.tsx          # Componente de botón con colores\n│   ├── Card.tsx            # Componente de tarjeta con colores\n│   └── ColorDemo.tsx       # Demostración de la librería\n└── README-COLORS.md        # Esta documentación\n```\n\n## Categorías de Colores\n\n### 1. Colores Base del Sistema\n- `--background-color`: Fondo principal\n- `--background-secondary`: Fondo secundario\n- `--foreground-color`: Texto principal\n- `--foreground-secondary`: Texto secundario\n\n### 2. Colores Principales\n- `--primary-color`: Color primario de la marca\n- `--primary-hover`: Estado hover del color primario\n- `--primary-light`: Versión clara del color primario\n- `--primary-dark`: Versión oscura del color primario\n\n### 3. Colores Secundarios\n- `--secondary-color`: Color secundario de la marca\n- `--secondary-hover`: Estado hover del color secundario\n- `--secondary-light`: Versión clara del color secundario\n- `--secondary-dark`: Versión oscura del color secundario\n\n### 4. Colores de Acento\n- `--accent-color`: Color de acento\n- `--accent-hover`: Estado hover del color de acento\n- `--accent-light`: Versión clara del color de acento\n- `--accent-dark`: Versión oscura del color de acento\n\n### 5. Colores de Botones\n- `--button-color-principal`: Color para botones principales\n- `--button-color-secundario`: Color para botones secundarios\n- `--button-color-success`: Color para botones de éxito\n- `--button-color-danger`: Color para botones de peligro\n- `--button-color-warning`: Color para botones de advertencia\n\n### 6. Estados de Interacción\n- `--color-success`: Color de éxito\n- `--color-error`: Color de error\n- `--color-warning`: Color de advertencia\n- `--color-info`: Color de información\n- (+ versiones light de cada uno)\n\n### 7. Escala de Grises\n- `--gray-50` hasta `--gray-900`: Escala completa de grises\n\n### 8. Colores de Borde\n- `--border-color`: Color de borde estándar\n- `--border-color-hover`: Color de borde en hover\n- `--border-color-focus`: Color de borde en foco\n\n## Cómo Usar la Librería\n\n### Método 1: CSS Variables (Recomendado)\n\n```css\n.mi-componente {\n  background-color: var(--button-color-principal);\n  color: var(--foreground-color);\n  border: 1px solid var(--border-color);\n}\n\n.mi-componente:hover {\n  background-color: var(--primary-hover);\n  border-color: var(--border-color-hover);\n}\n```\n\n### Método 2: En Componentes React con TypeScript\n\n```tsx\nimport { colors } from '@/lib/colors';\n\nconst MiComponente = () => {\n  return (\n    <div \n      style={{\n        backgroundColor: colors.buttonColorPrincipal,\n        color: colors.foregroundColor,\n        border: `1px solid ${colors.borderColor}`\n      }}\n    >\n      Contenido\n    </div>\n  );\n};\n```\n\n### Método 3: Con Tailwind CSS (Usando Variables CSS)\n\n```tsx\n<div className=\"bg-[var(--button-color-principal)] text-[var(--foreground-color)] border-[var(--border-color)]\">\n  Contenido\n</div>\n```\n\n## Cambiar Colores Globalmente\n\n### Para cambiar un color en toda la aplicación:\n\n1. **Editar en CSS Variables** (Opción 1):\n   - Abre `app/globals.css`\n   - Modifica el valor de la variable CSS correspondiente\n   - El cambio se aplicará automáticamente en toda la app\n\n```css\n:root {\n  /* Cambiar el color principal de azul a verde */\n  --button-color-principal: #10b981; /* Antes era #3b82f6 */\n}\n```\n\n2. **Editar en TypeScript** (Opción 2):\n   - Abre `lib/colors.ts`\n   - Modifica los valores en el objeto `rawColors`\n   - Regenera las CSS variables si es necesario\n\n## Ejemplos Prácticos\n\n### Cambiar Color de Todos los Botones Principales\n\n```css\n/* En app/globals.css */\n:root {\n  --button-color-principal: #ef4444; /* Cambiar a rojo */\n}\n```\n\nEste cambio afectará automáticamente a:\n- Todos los botones con `variant=\"primary\"`\n- Cualquier elemento que use `var(--button-color-principal)`\n- Componentes que importen `colors.buttonColorPrincipal`\n\n### Personalizar Tema Completo\n\n```css\n/* Tema personalizado verde */\n:root {\n  --primary-color: #10b981;\n  --primary-hover: #059669;\n  --secondary-color: #14b8a6;\n  --accent-color: #06d6a0;\n  --button-color-principal: #10b981;\n}\n```\n\n## Componentes Incluidos\n\n### Button\nComponente de botón con múltiples variantes que usan la librería de colores:\n\n```tsx\nimport Button from '@/components/Button';\n\n<Button variant=\"primary\">Botón Principal</Button>\n<Button variant=\"success\">Botón de Éxito</Button>\n<Button variant=\"danger\">Botón de Peligro</Button>\n```\n\n### Card\nComponente de tarjeta con diferentes estados visuales:\n\n```tsx\nimport Card from '@/components/Card';\n\n<Card title=\"Mi Tarjeta\" variant=\"success\">\n  Contenido de la tarjeta\n</Card>\n```\n\n### ColorDemo\nComponente de demostración que muestra toda la paleta de colores:\n\n```tsx\nimport ColorDemo from '@/components/ColorDemo';\n\n<ColorDemo />\n```\n\n## Soporte para Modo Oscuro\n\nLa librería incluye soporte automático para modo oscuro usando `@media (prefers-color-scheme: dark)`. Los colores se ajustan automáticamente según las preferencias del sistema del usuario.\n\n## Mejores Prácticas\n\n1. **Usa nombres semánticos**: Prefiere `--button-color-principal` sobre `--blue-500`\n2. **Mantén consistencia**: Usa siempre la librería en lugar de colores hardcodeados\n3. **Documenta cambios**: Comenta por qué cambias un color específico\n4. **Prueba ambos modos**: Verifica que los colores funcionen en modo claro y oscuro\n5. **Usa TypeScript**: Aprovecha el tipado para evitar errores\n\n## Extender la Librería\n\n### Agregar Nuevos Colores\n\n1. **Añadir variable CSS**:\n```css\n:root {\n  --mi-nuevo-color: #hexcode;\n}\n```\n\n2. **Añadir al TypeScript**:\n```typescript\nexport const colors = {\n  // ... colores existentes\n  miNuevoColor: 'var(--mi-nuevo-color)',\n};\n```\n\n3. **Actualizar interfaz** (opcional):\n```typescript\nexport interface ColorPalette {\n  // ... propiedades existentes\n  miNuevoColor: string;\n}\n```\n\n## Comandos Útiles\n\n```bash\n# Ejecutar la aplicación\nnpm run dev\n\n# Verificar tipos TypeScript\nnpm run type-check\n\n# Build de producción\nnpm run build\n```\n\n---\n\n**¡Tu librería de colores está lista!** 🎨\n\nAhora puedes cambiar cualquier color desde un solo lugar y ver los cambios reflejados automáticamente en toda tu aplicación.
